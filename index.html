Configurar Firebase

Para que la app funcione con datos en la nube, seguí estos pasos:

  1. Entrá a console.firebase.google.com
  2. Creá un proyecto (o usá uno existente)
  3. Activá Authentication → Sign-in method → Anónimo
  4. Creá una base Firestore (modo producción)
  5. En Reglas de Firestore, pegá esto:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null
                        && request.auth.uid == userId;
    }
  }
}
  1. Project settings → Your apps → Web → copiá la config
  2. Pegá los valores en index.html (buscá firebaseConfig)
  3. Subí de nuevo a Vercel

Nota: con Auth anónima, cada navegador/dispositivo tiene su propio usuario. Los datos se guardan en la nube por dispositivo. Si más adelante querés sync entre celulares, se puede agregar login con Google.
